# संत विसोबा खेचर डेटाबेस (Sant Visoba Khechar Extracted Data)

हा डेटाबेस [https://www.santsahitya.in/visoba/](https://www.santsahitya.in/visoba/) या संकेतस्थळावरून गोळा केलेला आहे.

## समाविष्ट फाइल्स (Files Included):

1. **`visoba_data.json`** - संपूर्ण डेटा JSON स्वरूपात (Metadata, URLs, Section Content, Images).
2. **`sant_visoba_khechar_mahiti.md`** - संत विसोबा खेचर आणि संत नामदेव महाराज यांच्या भेटीची व अनुग्रहाची सविस्तर माहिती.
3. **`sant_visoba_khechar_samadhi.md`** - बार्शी, जिल्हा सोलापूर येथील संत विसोबा खेचर समाधी स्थानाची माहिती.

## संक्षिप्त सारंश (Summary):
- **गुरु:** संत ज्ञानेश्वर महाराज
- **शिष्य:** संत नामदेव महाराज
- **संप्रदाय:** शैव पंथ, नाथ संप्रदाय, वारकरी संप्रदाय
- **समाधी स्थान:** उत्तरेश्वर मंदिर परिसर, बार्शी, जिल्हा सोलापूर, महाराष्ट्र
